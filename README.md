# AccessLearn AI

AccessLearn AI transforms learning content into accessible formats including Braille, DAISY audiobooks, visual mindmaps, interactive flashcards, sign language animations, and plain-language adaptations.

## Key Capabilities
- **WCAG 2.2 AAA & APCA Contrast Engine**: Real-time accessible color palette generation.
- **Color Vision Deficiency Simulation**: Protanopia, Deuteranopia, Tritanopia, and Achromatopsia filters.
- **Cognitive & Reading Assessment**: Lexile measure, syllable complexity, and executive function focus pacing.
- **Assistive Navigation**: Screen reader heading tree navigator and focus guide reading ruler.
- **Interactive Study Tools**: Auto-generated flashcard decks and concept mindmap trees.
- **LMS Interoperability**: SCORM 2004 & IMS Common Cartridge manifest export.
